## 💻 Projeto

O Sistema de Visitas que foi criado como uma experiência personalizada e bem-humorada para identificar quem está tentando entrar. Através de uma interface com estética mais dark mas sem deixar a parte fofa de lado, o visitante informa seu nome e o sistema decide seu destino com base em condições.
